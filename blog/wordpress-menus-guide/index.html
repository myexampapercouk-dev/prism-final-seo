WordPress Menus: A Practical Guide to Building Site Navigation

How to create, edit and organise WordPress menus in block and classic themes, including menu locations, dropdowns, mobile menus and common mistakes to avoid.

By the Prism Works Studio team · 1 November 2026 · 8 min read

Key takeaways

  • How you edit menus in WordPress depends on whether your site uses a block theme or a classic theme.
  • Menus should reflect how visitors think about your content, not your internal structure or every page you have.
  • Check menus on mobile and with a keyboard after every change, because dropdowns often behave differently there.

The menu is one of the first things visitors use on a website, and one of the easiest things to get wrong. In WordPress, menus are flexible: you can add pages, posts, categories and custom links, arrange them into dropdowns and place them in different parts of your theme. That flexibility also means menus can quietly become cluttered, inconsistent or broken over time.

This guide explains how menus work in WordPress, how to edit them in both block themes and classic themes, and how to keep them useful as your site grows. If you are still deciding what should go in your navigation in the first place, our guide to website navigation structure covers the planning side.

How WordPress menus work

A WordPress menu is a list of links that your theme displays somewhere on the site, usually in the header, and often in the footer too. Each item in the menu points to something: a page, a post, a category archive, a product category if you run a shop, or a custom web address.

Menus are stored separately from your pages. That means creating a new page does not automatically add it to your navigation, and deleting a page does not always remove it cleanly from a menu. Keeping the two in step is part of routine site maintenance.

There are two main ways to manage menus, depending on the type of theme your site uses.

Block themes and the Navigation block

Block themes use the Site Editor, found under Appearance, then Editor. Here, the header and footer are template parts made of blocks, and the menu is a Navigation block. You edit the menu directly in place: click the Navigation block, then add, remove or reorder links in the block settings or the list view.

Navigation menus in block themes are saved as reusable items, so the same menu can be used in more than one template part. If you edit a menu in one place, the change usually appears wherever that menu is used, which is helpful but worth remembering before you make changes.

Classic themes and the Menus screen

Classic themes use the Menus screen under Appearance, then Menus. You create a named menu, add items from the panels on the left, drag them into order and then assign the menu to a location your theme provides, such as Primary or Footer. Some classic themes also let you manage menus through the Customiser.

If you do not see a Menus option under Appearance, your site is probably using a block theme. If you see both, your theme may support a mix of approaches, so check your theme's documentation before deciding where to make changes.

Creating a menu step by step

The exact screens differ between theme types, but the process is broadly the same.

  1. Decide what the menu is for. A main header menu, a footer menu and a mobile menu often have different jobs. Write down the items each one needs before you open the editor.
  2. Create or select the menu. In a block theme, select the Navigation block and choose or create a menu. In a classic theme, create a new menu on the Menus screen and give it a clear name.
  3. Add items. Add pages, posts, categories or custom links. Use the search box to find content quickly on larger sites.
  4. Edit labels. The menu label does not have to match the page title. A page titled "Our Services and Pricing Information" might work better in a menu as "Services".
  5. Arrange the order and nesting. Drag items into order. To create a dropdown, nest an item beneath a parent.
  6. Assign or place the menu. In a classic theme, tick the location. In a block theme, make sure the Navigation block in your header uses the right menu.
  7. Save and test. Check the live site on desktop and mobile before moving on.

Dropdowns and sub-menus

Dropdown menus let you group related pages under a parent item. They can tidy up a busy header, but they also hide content, and they can be awkward on touch screens and for keyboard users.

A few practical points help:

  • Keep nesting shallow. One level of dropdown is usually enough. Menus that open into a second or third level are hard to use, especially on mobile.
  • Decide what the parent item does. If the parent is a link, some visitors will click it expecting a page, while others expect it to open the dropdown. Make sure the parent page exists and is useful, or use a parent that only opens the sub-menu if your theme supports that clearly.
  • Use clear, short labels. Dropdown items are scanned quickly. Plain words work better than clever ones.
  • Avoid duplicating everything. You do not need every page in the menu. Put the important destinations there and link to others from within the content.

Custom links and special items

Custom links let you add any web address to a menu. They are useful for linking to a specific section of a page, a contact form or an external booking system you control. Be careful with them, though, because WordPress will not update a custom link if the page it points to moves. If you change a page address, check your menus for custom links that still point to the old one.

You can also add category and tag archives to menus. On a blog or a shop, linking to a category can be a good way to give visitors a route into a group of related content. Make sure the archive pages themselves are tidy and have helpful introductions, so the menu leads somewhere worthwhile.

Many themes support extra options for menu items, such as opening a link in a new tab, adding a CSS class or adding a description. In a classic theme, some of these are hidden by default: use the Screen Options panel at the top of the Menus screen to reveal them. Use the new tab option sparingly, because it can be disorienting for visitors.

Mobile menus

On smaller screens, most themes collapse the main menu behind a button, often called a hamburger menu. The way this works depends on your theme. In block themes, the Navigation block has an overlay setting that controls when the mobile menu appears.

Test your mobile menu properly:

  • Open and close the menu and check every item is visible and tappable.
  • Check dropdowns can be opened on a touch screen without accidentally following the parent link.
  • Make sure the menu button is easy to find and clearly labelled for screen readers.
  • Check long labels do not wrap awkwardly or push other items off screen.

If your main menu is long, it may be worth creating a simpler menu for mobile, if your theme allows it, rather than squeezing everything in.

Footer and secondary menus

Footer menus are a good home for links that matter but do not need a place in the header, such as your privacy policy, terms, accessibility statement, careers page or delivery information. Many sites use several small footer menus grouped under headings.

Some themes also offer a secondary or top bar menu above the main header, often used for account links, contact details or a phone number. Keep this short, so it supports the main menu rather than competing with it.

Accessibility considerations

Menus should work for everyone, including people who navigate with a keyboard or use assistive technology. In the UK, public sector bodies have specific accessibility obligations, and other organisations may have duties under equality law; if you are unsure what applies to you, it is sensible to take advice. Whatever your situation, accessible menus are simply easier to use.

  • Check you can move through the menu with the Tab key and open dropdowns without a mouse.
  • Make sure there is a visible focus style so keyboard users can see where they are.
  • Use descriptive labels rather than vague ones such as "More" or "Click here".
  • Avoid menus that only open on hover with no keyboard or tap alternative.

Well-built themes handle much of this for you, but customisations can break it, so test after changes.

Common menu mistakes

Too many items

Adding every new page to the header makes the menu harder to scan. Review it regularly and move less important links to the footer or into page content.

Broken or outdated links

When pages are deleted, renamed or moved, menu items can point to the wrong place or disappear. After restructuring content, review every menu and set up redirects for any changed addresses.

Different menus in different places

On block themes in particular, it is possible to end up with several similar menus used in different templates. Visitors may see a different header on some pages. Check which menu each template part uses and consolidate where you can.

Labels that only make sense internally

Menu labels should use the words your visitors use. Internal team names, product codes or jargon can confuse people who are new to your business.

Keeping menus tidy over time

Treat your menus as part of regular site housekeeping. When you add or remove a significant page, ask whether the menu needs to change. Every so often, review each menu against your current priorities and check it on mobile.

FAQs

Why can I not find the Menus option in WordPress?

If Appearance does not show a Menus option, your site is most likely using a block theme. In that case, menus are managed through the Navigation block in the Site Editor instead.

Can I have different menus on different pages?

Yes, though how you do it depends on your theme. Block themes let you use different template parts with different Navigation blocks. Classic themes may need theme options or custom development to show different menus on specific pages.

How many items should a main menu have?

There is no fixed number. Aim for a menu visitors can scan quickly, focused on the main things they come to your site for, and move secondary links elsewhere.

Does the menu affect SEO?

Menus help search engines discover and understand your important pages, because they are linked from every page. Clear, descriptive labels and a sensible structure help both visitors and search engines.

Will changing my menu break anything?

Changing menu items does not change page addresses, so it should not break links elsewhere. However, removing a page from the menu can make it harder to find, so make sure important content is still linked from somewhere.
