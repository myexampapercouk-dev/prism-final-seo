Shopify Speed Optimisation: How to Make Your Store Load Faster

Shopify speed optimisation guide for UK stores: apps, images, themes, scripts and Core Web Vitals, with practical fixes that help shoppers and SEO.

By the Prism Works Studio team · 31 October 2026 · 7 min read

Key takeaways

  • Unused apps, heavy images and third-party scripts are among the most common causes of slow Shopify stores.
  • Measure real-user performance and Core Web Vitals before and after changes, not just a single test score.
  • Speed work should protect conversion features, so test changes rather than stripping things out blindly.

Shopify speed optimisation is the work of making your store load and respond faster for real shoppers. Shopify provides fast hosting and a global content delivery network, but what you add on top, such as your theme, apps, images and tracking scripts, decides how quickly pages actually feel. A faster store is easier to browse, especially on mobile, and supports both conversions and search performance.

This guide is for UK store owners and ecommerce teams who suspect their Shopify site is slower than it should be. For general principles across all platforms, see our website speed optimisation guide.

How to measure Shopify speed properly

Start with data rather than guesswork. Useful sources include:

  • Shopify's online store speed report in your admin, which gives an overview over time.
  • Google Search Console's Core Web Vitals report, which shows real-user data grouped by page type.
  • PageSpeed Insights and similar lab tools, which help diagnose specific problems on individual pages.

Test your homepage, a collection page, a product page and the cart, as each has different weight. Lab scores vary between runs, so look for patterns rather than chasing a single number. Our Core Web Vitals guide explains the metrics.

Audit your apps

Apps are one of the most common causes of slow Shopify stores. Many inject JavaScript and styles on every page, even when their feature is only used in one place. Removing an app from your admin does not always remove the code it added to your theme.

  • List every installed app and what it does.
  • Remove apps you no longer use, then check your theme files for leftover code.
  • Look for apps that duplicate each other or a feature your theme already offers.
  • Prefer apps built on theme app extensions, which tend to load more cleanly.

Optimise images and media

Product photography matters, but oversized files slow pages down. Upload images at sensible dimensions, compress them before upload and let Shopify serve modern formats and responsive sizes through your theme. Make sure images below the fold are lazy loaded, while your main hero or product image loads promptly. Autoplaying background videos and large sliders on the homepage are frequent culprits worth questioning.

Choose and maintain a lean theme

Modern Shopify themes are generally built with performance in mind, but older or heavily customised themes can carry years of unused code. If your theme is several versions behind, an update or move to a newer theme may help. When customising, avoid loading large libraries for small effects and keep custom sections efficient. Our website and ecommerce development service covers how to customise without bloat.

Control third-party scripts

Tracking pixels, chat widgets, review widgets, pop-ups and heatmap tools all add weight. Each may be useful, but together they can delay how quickly a page becomes usable. Review what is installed, remove duplicates, load non-essential tools after the main content and use Shopify's customer events where it suits your tracking setup. Make sure consent settings still work after any changes.

Reduce layout shift and slow interactions

Pages that jump around as they load frustrate shoppers. Set dimensions for images and embeds, avoid injecting banners above content after load and keep fonts to a small number of weights. For slow interactions, look at heavy scripts running on filters, variant pickers and add-to-cart buttons.

Balance speed with conversion

Speed is a means to an end. Some apps and scripts earn their place by helping shoppers buy. Rather than removing everything, test the impact of changes on conversion rate as well as load time. Our ecommerce CRO guide covers that side.

Common mistakes

  • Chasing a perfect lab score while ignoring real-user data.
  • Uninstalling apps but leaving their code behind.
  • Uploading huge, uncompressed product photos.
  • Stacking several pop-ups and widgets on every page.
  • Making theme edits on the live theme without a backup.

Collection and product page specifics

Collection pages often load many product images, swatches and quick-view features at once. Limit the number of products shown per page to something sensible, lazy load images beyond the first row and question whether features like quick view or hover image swaps are worth their cost. Filters should respond quickly; if filtering feels sluggish, look at which scripts run when a filter changes.

Product pages tend to carry the most apps: reviews, upsells, size guides, wishlists, delivery estimators and more. Each may load its own script. Consider whether every widget needs to appear immediately or whether some can load after the main product information. Keep the product image, title, price, variant picker and add-to-cart button as the priority.

Fonts and icons

Custom fonts help a brand look distinctive, but each weight and style is another file to download. Stick to a small number of weights, use system fonts where they fit the brand and make sure text remains visible while fonts load. Replace large icon font libraries with lightweight inline icons where possible.

Keep speed work going

Speed is not a one-off fix. New apps, campaign banners, tracking tags and theme changes all add weight over time. Build a simple routine:

  • Check the speed report and Core Web Vitals monthly.
  • Review apps and scripts every few months and remove what you no longer use.
  • Test the performance impact of any new app before rolling it out fully.
  • Compress new images as part of your product upload process.

A short checklist shared with everyone who edits the store prevents most regressions.

Speed and multi-market stores

If you sell into several markets, extra apps for currency, translation or geolocation can add weight. Shopify's built-in markets features may cover some of this without additional scripts. Test speed from the perspective of customers in each region you serve.

Where to start if you only have a day

If time is limited, focus on the changes most likely to make a difference:

  1. Remove apps you no longer use and clean out their leftover code.
  2. Compress and resize the largest images on your homepage and top product pages.
  3. Remove or defer non-essential widgets and tracking tags.
  4. Replace autoplaying homepage video or heavy sliders with a single, well-optimised image.
  5. Re-test the same pages and compare against your starting point.

These steps rarely require deep code changes and can often be done by a confident store owner, with care and a theme backup.

When to bring in a developer

Some problems sit deeper in theme code: render-blocking scripts, inefficient Liquid loops, large custom JavaScript bundles or poorly built sections. If basic clean-up has not helped, a developer can profile your theme, find the specific bottlenecks and fix them without removing features your shoppers rely on. Ask for before-and-after measurements on the same pages so you can see what changed.

FAQs

Why is my Shopify store slow?

Common causes include too many apps, leftover app code, large images, heavy themes and third-party scripts such as tracking pixels and widgets.

Does Shopify speed affect SEO?

Page experience, including Core Web Vitals, is one of many factors Google considers. Speed also affects how shoppers behave, which matters regardless of rankings.

Is the Shopify speed score accurate?

It is a useful guide, but it is based on lab testing. Combine it with real-user data from Search Console for a fuller picture.

Will removing apps break my store?

It can if a feature relies on them. Check what each app does, back up your theme and test after removal.

Should I change theme to improve speed?

Sometimes. If your theme is outdated or heavily modified, a modern theme can help, but weigh it against redesign effort and SEO considerations.

How often should I check my store speed?

A monthly check of the speed report and Core Web Vitals is a sensible routine, plus a check whenever you install a new app or make significant theme changes.

Do pop-ups slow down Shopify?

They can. Pop-up apps load extra scripts and can cause layout shift. If you use one, keep it lightweight, delay it and check its impact on mobile.

Are large product images bad for speed?

Oversized files are. Upload images at sensible dimensions, compress them and let your theme serve responsive sizes, so shoppers get sharp images without unnecessary weight.

Can tracking scripts be loaded later?

Many non-essential tools can load after the main content. Check with whoever manages your analytics and advertising so conversion tracking still records accurately.
