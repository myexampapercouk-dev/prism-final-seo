Maintenance Mode Pages: How to Take a Website Offline Without Harm

When to use a maintenance mode page on a WordPress or Shopify site, what it should say, which status code to return and how to avoid hurting search visibility.

By the Prism Works Studio team · 1 November 2026 · 7 min read

Key takeaways

  • A maintenance mode page tells visitors a site is temporarily unavailable and should explain what is happening and when to come back.
  • For temporary downtime, the page should return a 503 status code so that search engines understand it is not permanent.
  • Many updates can be tested on a staging site first, keeping time in maintenance mode as short as possible.

Sometimes a website needs to be taken offline briefly. You might be applying a significant update, migrating to a new setup, fixing a problem or relaunching with a new design. During that time, showing visitors a half-finished or broken site is rarely a good idea. A maintenance mode page offers a simple alternative: a temporary message explaining that the site is unavailable and will be back soon.

Done well, a maintenance page protects your reputation and your search visibility. Done badly, it can confuse visitors and send the wrong signals to search engines. This guide covers when to use maintenance mode, what the page should say, how it works on WordPress and Shopify, and the technical details that matter.

What is a maintenance mode page?

A maintenance mode page replaces your normal site for visitors while work takes place. Logged-in administrators can usually still see and work on the real site behind it. Once the work is finished, maintenance mode is switched off and visitors see the site as normal.

It is different from a "coming soon" page, which is used before a site has launched at all. The principles are similar, but a maintenance page is about a temporary interruption to an existing site.

When maintenance mode makes sense

Maintenance mode is useful when visitors could otherwise see something broken or inconsistent. Examples include:

  • Major updates to a theme, plugins or core software where changes need checking before visitors arrive.
  • Moving a site to a new server or making significant configuration changes.
  • Replacing a design on a live site where the old and new versions cannot sit side by side.
  • Fixing a serious problem, such as a fault affecting checkout or forms.

It is often not needed for routine, small updates, which many sites handle without visible disruption. And in many cases, the better approach is to do the work on a staging copy first, so that the live site only needs to be paused briefly, if at all. Our guide to website staging and testing explains this approach.

What a good maintenance page says

A maintenance page does not need to be elaborate. It needs to be clear and reassuring.

A plain explanation

Tell visitors the site is temporarily unavailable while you make improvements or carry out maintenance. Avoid technical jargon, and avoid alarming language that suggests something has gone badly wrong.

When to come back

If you have a reasonable idea of when the site will return, say so, for example "We expect to be back later today". If you are not sure, a general "We will be back shortly" is better than a precise time you might miss. Update the message if things take longer than planned.

How to get in touch

Some visitors will need you urgently. Include a phone number or email address so they can still reach you, particularly if you are a service business or have customers with open orders.

Your branding

Use your logo and brand colours so visitors know they are in the right place. A bare server message can make people think the site has been abandoned or compromised.

Optional extras

Links to your social media profiles or a short note about what is coming can be helpful. Keep it brief, though; this is a holding page, not a full marketing page.

The status code matters

When a browser or search engine requests a page, the server returns a status code. For a maintenance page, the appropriate code is generally 503 Service Unavailable. This tells search engines that the site is temporarily down and that they should come back later, rather than treating the maintenance message as your new content.

A 503 response can also include a header suggesting when to try again. Google's guidance indicates that brief 503 periods are handled as temporary, though extended unavailability over a long period may eventually affect how a site is treated in search. Keeping maintenance windows short is the safest approach.

The mistakes to avoid are returning a normal 200 status code, which can lead search engines to index the maintenance message in place of your real pages, or redirecting all pages to a separate maintenance URL. Our 404 page design guide explains status codes in a little more detail.

Maintenance mode on WordPress

WordPress has a basic maintenance mode built in. When you update core software, themes or plugins through the dashboard, WordPress briefly shows a simple message to visitors while files are being replaced. This usually lasts only moments and is cleared automatically once the update completes.

Occasionally, if an update is interrupted, a site can get stuck showing that message. This is typically caused by a leftover temporary file in the site's root folder that signals maintenance is in progress. Removing it, or asking your host or developer to do so, usually restores the site. It is worth checking the site afterwards, as an interrupted update can leave things partly updated.

For planned work, many WordPress sites use a dedicated maintenance mode feature, either from the theme or a plugin, that shows a branded page to visitors while logged-in users continue working. If you go this route, check that it returns a 503 status code and that you can easily switch it off. Our WordPress plugin audit guide covers choosing plugins carefully, and keeping regular backups is essential before any major work. See our guide to a website backup and recovery plan.

Shopify and password protection

Shopify does not offer a maintenance mode in quite the same way. The nearest equivalent is the online store password page, which restricts access to the storefront and shows a customisable message to visitors. It is often used before launch, but it can also be used to pause a store temporarily.

Shopify's platform is hosted and maintained by Shopify, so you do not need maintenance mode for platform updates. For changes you control, such as a redesign, the usual approach is to work on an unpublished theme, preview it thoroughly and publish it when ready. This avoids taking the store offline at all. Our guide to Shopify theme updates explains how to work with theme copies safely.

If you do enable password protection on a live store, think carefully about the timing and how it may affect customers, open orders and any advertising campaigns that link to the store.

Reducing the need for downtime

The best maintenance window is a short one. A few practices help keep downtime to a minimum:

  • Test on staging first. Make and check changes on a copy of the site before applying them to the live version.
  • Take a backup. Always have a recent, restorable backup before significant work.
  • Choose quieter times. Your analytics can show when visitor numbers are typically lower, which may be a better time for planned work.
  • Prepare a checklist. Write down what will be done and how you will check it, so the work moves quickly.
  • Plan a rollback. Know how you will restore the previous version if something goes wrong.

If you are moving hosts, our guide to changing website hosting without downtime covers approaches that can avoid a maintenance window altogether.

After maintenance: checks to make

When the work is done, switch maintenance mode off and check the site from a visitor's point of view, ideally in a private browser window where you are not logged in.

  • Confirm the homepage and key pages load correctly.
  • Test contact forms, search and, for shops, the cart and checkout.
  • Check the site on a phone as well as a desktop.
  • Make sure any caching has been cleared so visitors are not shown the old maintenance page.
  • Look in Google Search Console over the following days for any unexpected crawl errors.

FAQs

Will a maintenance page hurt my SEO?

A short maintenance period that returns a 503 status code is generally treated as temporary by search engines. Problems are more likely if the page returns a normal 200 status, redirects all pages elsewhere or stays in place for a long time.

How do I fix a WordPress site stuck in maintenance mode?

This usually happens when an update is interrupted and a temporary maintenance file is left in the site's root folder. Removing that file, or asking your host or developer to, typically brings the site back. Check afterwards that all updates completed properly.

Does Shopify have a maintenance mode?

Not exactly. Shopify offers a password page that restricts access to the storefront and can be customised with a message. For redesigns, working on an unpublished theme and publishing when ready usually avoids taking the store offline.

What should a maintenance page say?

Keep it simple: explain that the site is temporarily unavailable, give an idea of when it will return, provide a way to get in touch and include your branding so visitors know they are in the right place.

Is a maintenance page the same as a coming soon page?

They are similar but serve different purposes. A coming soon page is used before a site launches, while a maintenance page temporarily replaces an existing site during work. Both should be clear, branded and set up with appropriate technical settings.
