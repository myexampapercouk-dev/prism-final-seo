TikTok Pixel Setup: How to Track Results From TikTok Ads

How to set up the TikTok Pixel: create it in Events Manager, install it, choose events, handle UK cookie consent and test it before your ads go live.

By the Prism Works Studio team · 8 November 2026 · 7 min read

Key takeaways

  • The TikTok Pixel tells TikTok which ad viewers went on to enquire or buy, which helps campaigns optimise and report properly.
  • Track a small number of meaningful events, such as purchases or completed enquiries, rather than every click.
  • Make the pixel respect cookie consent, and test it with TikTok's own tools before you spend money on ads.

To set up the TikTok Pixel, create a pixel in TikTok Ads Manager's Events Manager, install its code on your website directly, through a platform integration or through a tag manager, then choose the events you want to track and test them. Once it fires correctly, and only after visitors consent to advertising cookies, TikTok can measure and optimise your ads.

This guide is for UK small business owners who are running, or planning to run, TikTok Ads. It explains what the pixel does, the main installation routes, which events are worth tracking, how UK consent rules fit in and how to check it works. TikTok updates its tools often, so check TikTok's current Business Help Centre for the exact steps and menu names.

What the TikTok Pixel does

When someone sees your ad on TikTok and later visits your website, TikTok has no way of knowing what happened next unless your site tells it. The pixel is a small piece of code that does exactly that. It reports actions such as viewing a product, adding to basket, starting checkout, completing a purchase or submitting an enquiry form.

That information is used in three ways. First, it shows you which campaigns lead to real results rather than just views. Second, TikTok's delivery system uses it to find more people likely to take the same action. Third, it lets you build audiences of past visitors for retargeting. Without the pixel, you are judging campaigns on clicks alone, which rarely tells the full story. If you are new to the platform, our overview of TikTok Ads for UK businesses covers when it makes sense.

Before you start

  • A TikTok Ads Manager account owned by the business, ideally inside a Business Center so access can be managed and shared safely.
  • Access to your website, whether that is the Shopify admin, WordPress dashboard, another builder, or a tag manager container.
  • A cookie consent tool that can block or allow advertising tags based on the visitor's choice.
  • A short list of actions that matter to your business, such as purchases, booking requests or quote forms.
  • An updated privacy notice that mentions advertising pixels. Our guide to website terms and privacy policies covers the basics.

TikTok Pixel setup: the main installation routes

There are three common ways to install the pixel. Which one suits you depends on your website platform and how much control you want.

RouteBest forThings to watch
Platform integrationShopify and other ecommerce platforms with an official TikTok app or channelQuick to set up, but check which events it sends and do not also add the code manually
Tag managerSites that already manage tags in one placeFlexible and easy to control with consent, but needs careful trigger set-up
Manual codeSimple sites without a tag manager or integrationNeeds code edits, and each event must be added by hand

For Shopify stores, the TikTok sales channel is usually the simplest starting point, because it can connect your catalogue and send standard shopping events. Our guide to Shopify sales channels explains how channels work. For WordPress and other sites, a tag manager keeps your tracking tidy and makes it easier to tie tags to consent.

Step-by-step set-up

  1. Create the pixel. In TikTok Ads Manager, open the events area, choose to connect a web data source and give the pixel a clear name, such as the business name and website.
  2. Choose an installation method. Select the partner integration if one is offered for your platform, or choose manual installation to get the base code.
  3. Add the base code. The base code loads on every page. With a tag manager, create a tag for it that fires on all pages once advertising consent is given.
  4. Set up events. Add the standard events that match your list. TikTok offers named events for common actions, and using these rather than custom names helps its optimisation.
  5. Pass values where relevant. For purchases, send the order value and currency (GBP) so you can see return on ad spend.
  6. Test. Use TikTok's testing tools and browser helper to confirm each event fires once, at the right moment.
  7. Connect it to campaigns. When you build a campaign that optimises for website conversions, pick the pixel and the event you care about most.

Which events to track

Track what reflects real business value. A simple service business might only need a completed enquiry and a phone number click. An online shop will usually want product views, add to basket, checkout started and purchase. Avoid tracking every scroll and minor click, because noisy events make reports harder to read and can lead campaigns to optimise for the wrong thing.

Keep your event list consistent with the events you track in Google Analytics 4 and other ad platforms. If you already followed our Meta Pixel setup guide, reuse the same list of actions. It makes comparing channels far easier. Our GA4 setup guide covers the analytics side.

Consent, UK GDPR and PECR

Under PECR and UK GDPR, advertising pixels generally need the visitor's consent before they run on UK websites. That means the TikTok Pixel should not fire until someone has accepted advertising or marketing cookies in your banner. Most consent tools can block the pixel by category, and most tag managers can use consent as a trigger condition. Our article on cookie banner design in the UK explains how to make the choice clear and fair.

TikTok also offers server-side options, often described as an events API, which send event data from your server rather than the browser. These can improve data quality, but they do not remove the need for consent or for handling personal data lawfully. This is general information rather than legal advice. Check the ICO's guidance and your own legal adviser if you are unsure.

How to check your pixel is working

  • Use TikTok's diagnostic and test event tools in Events Manager to watch events arrive as you browse.
  • Install TikTok's browser helper extension, if available, to see which events fire on each page.
  • Make a test journey from landing page to enquiry or checkout, and confirm each event appears once.
  • Decline cookies in your banner and confirm the pixel does not fire.
  • Check any warnings in Events Manager, such as missing values or duplicate events, and fix them.

Common TikTok Pixel mistakes

  • Double installation. Adding the pixel through a platform app and again by hand causes duplicate events and inflated results.
  • Purchase events on the wrong page. A purchase event that fires on the basket page will count browsing as buying.
  • Missing currency or value. Without these, return on ad spend cannot be calculated.
  • Firing before consent. This creates compliance risk and can undermine trust.
  • Not tagging links. Use UTM parameters on TikTok ad links so GA4 shows the traffic correctly. Our UTM tracking guide explains how.
  • Personal data in URLs. Never pass names, emails or phone numbers in page addresses where pixels can pick them up.

Using pixel data for retargeting

Once the pixel has gathered enough data, you can build audiences of people who visited certain pages or took certain actions, then show them follow-up ads. Keep frequency sensible and exclude recent buyers where possible. Our remarketing guide covers how to approach this across platforms without irritating people.

Custom events, server-side tracking, consent mode set-ups and reconciling numbers across TikTok, Meta, Google and GA4 take more time and experience. FAQs

How do I set up the TikTok Pixel?

Create a pixel in TikTok Ads Manager's Events Manager, install it through your platform's integration, a tag manager or manual code, add the events you want to track, then test with TikTok's tools. Make sure it only fires after visitors consent to advertising cookies.

Is the TikTok Pixel free?

Yes, there is no charge for creating or installing the pixel itself. You only pay for the ads you run, and possibly for any consent tool or developer time you use.

Do I need the TikTok Pixel if I only run awareness ads?

It is still worth installing. Even if you are not optimising for conversions yet, the pixel builds data and audiences you can use later, and helps you see whether awareness campaigns lead to site visits.

Can I use the TikTok Pixel on Shopify?

Generally yes. Shopify stores can usually connect through TikTok's official sales channel, which handles much of the set-up. Check Shopify's and TikTok's current help pages for the latest steps.

Does the TikTok Pixel need cookie consent in the UK?

In most cases, yes. Advertising pixels typically need consent under PECR before they run. Set your consent tool or tag manager so the pixel only fires once a visitor accepts the relevant cookies.

Why are my TikTok results different from GA4?

Each platform counts conversions in its own way, using different attribution windows and methods, and some visitors decline cookies. Expect differences, and focus on trends and consistent comparisons rather than matching numbers exactly.
