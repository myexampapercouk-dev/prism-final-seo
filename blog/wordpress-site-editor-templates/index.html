WordPress Site Editor Templates and Template Parts: A Practical Guide

How templates, template parts and patterns work in the WordPress site editor, when to use each, and how to edit them safely without breaking your layout.

By the Prism Works Studio team · 1 November 2026 · 7 min read

Key takeaways

  • Templates control the layout of whole types of page, while template parts are reusable sections such as headers and footers.
  • Patterns are for reusable content inside pages; templates and template parts are for site-wide structure.
  • Edit templates carefully, keep a record of changes and know how to reset a template to the theme default.

If your WordPress site uses a block theme, much of its layout is no longer locked away in theme files. The site editor lets you change headers, footers, blog layouts and archive pages directly in the dashboard. That is powerful, but it also introduces terms that can be confusing: templates, template parts, patterns and synced patterns all sound similar and do different jobs.

This guide explains each one in plain language, when to use which, and how to make changes without accidentally altering pages across the whole site. WordPress continues to develop the site editor, so labels and menu locations may change over time, but the concepts below have stayed broadly consistent.

What is the site editor?

The site editor is the part of WordPress used to design the overall structure of a site built with a block theme. Instead of editing a single page, you edit the layouts that pages and posts are displayed in. It uses the same blocks as the post editor, so if you are comfortable building a page with blocks, the site editor will feel familiar.

Classic themes do not use the site editor in the same way. If your theme is a classic theme, layouts are usually controlled through theme files, the customiser and widgets. Check which kind of theme you have before following any site editor guidance. Our WordPress block editor guide covers the basics of working with blocks.

Templates: layouts for whole types of page

A template defines how a type of content is displayed. A block theme typically includes templates for the front page, single blog posts, pages, archives, search results and the 404 page, among others. When a visitor opens a blog post, WordPress chooses the matching template and fills it with that post's content.

Because templates apply to every item of a type, a change to the single post template affects every blog post on the site. That is exactly what you want when adjusting a layout, and exactly what you need to be careful about when experimenting.

Custom templates

You can also create custom templates and assign them to individual pages or posts. A landing page without the usual sidebar, or a page with a full-width layout, are typical examples. Custom templates are useful, but each one is another layout to maintain, so create them only when a page genuinely needs a different structure.

The template hierarchy

WordPress follows a set order when choosing a template, moving from the most specific option to the most general. A template for one specific category, for instance, would be used ahead of the general archive template. Understanding this helps when a page does not look the way you expect: often a more specific template is being used instead of the one you edited.

Template parts: reusable sections of a layout

Template parts are sections used inside templates. The header and footer are the most familiar examples. Rather than building the header separately in every template, each template includes the same header template part. Edit the header once and the change appears everywhere it is used.

You can create other template parts too, such as a sidebar, a newsletter sign-up area or a call to action band that appears at the bottom of several templates. The rule of thumb is simple: if a section of layout repeats across templates and should always stay identical, it is a good candidate for a template part.

Navigation sits inside the header template part in many themes. If you are adjusting menu links, our WordPress menus guide explains how navigation is managed.

Patterns: reusable content blocks

Patterns are groups of blocks you can insert into pages, posts or templates. A pattern might be a testimonial layout, a pricing table design or a team section. There are two broad types to understand.

  • Unsynced patterns act as starting points. When inserted, the blocks become independent copies, so editing one copy does not change the others.
  • Synced patterns stay linked. Editing a synced pattern updates every place it appears, similar to how template parts behave.

Patterns are for content, while template parts are for layout structure. A useful test is to ask where the item lives. If it belongs to the frame around content, such as the header, it is a template part. If it is something an editor drops into the content area of a page, it is a pattern.

Choosing between templates, template parts and patterns

NeedBest fit
Change how all blog posts are laid outSingle post template
Give one landing page a different layoutCustom template
Update the header across the siteHeader template part
Reuse a call to action design on several pages, with different wordingUnsynced pattern
Show identical contact details in several places and update them onceSynced pattern

Choosing the right tool keeps the site easier to manage. Using templates for content, or copying the same header into many templates by hand, creates more places for inconsistencies to creep in.

Editing safely

Because template changes can affect many pages at once, it pays to work methodically.

  1. Take a backup first. Before larger changes, make sure you have a recent backup you know how to restore. See our website backup and recovery plan.
  2. Check which template is in use. Confirm you are editing the template that actually controls the page you are looking at.
  3. Use a staging site for big changes. Testing structural changes away from the live site reduces the risk of visitors seeing a broken layout.
  4. Review on mobile. Layout changes can look different on small screens, so preview at several widths.
  5. Write down what you changed. A short log makes it far easier to undo or explain changes later.

Resetting templates

When you edit a theme's template in the site editor, WordPress saves your customised version in the database rather than changing the theme files. In most cases you can clear those customisations and return to the theme's original version. This is a useful safety net, but resetting removes your changes, so note anything you want to keep first.

Theme updates

Because customised templates are stored separately, a theme update may not change templates you have already edited. That protects your work, but it also means you might miss improvements the theme author has made. Review theme update notes and compare layouts when updating. If you need deeper changes, a child theme may still be appropriate.

Templates and SEO

Templates shape the structure that search engines see on every page of a type, so they influence SEO more than many single-page edits. A few points are worth checking:

  • Each page should have one clear main heading. Check that templates do not add a second heading at the same level by mistake.
  • Blog post templates should show useful information such as the publish or updated date and the author or brand where appropriate.
  • Archive templates should give visitors a clear route to individual posts, with readable titles and excerpts.
  • Avoid heavy decorative elements in templates that slow every page down.

Keeping the setup tidy over time

Sites that are edited by several people can collect unused custom templates, duplicated template parts and patterns that nobody remembers creating. Review them periodically. Remove what is no longer used, rename items so their purpose is obvious, and keep the number of custom templates as small as practical.

It also helps to agree who can edit templates. Many content editors only need access to posts and pages, not the site editor. WordPress user roles let you limit who can change site-wide layouts.

FAQs

What is the difference between a template and a template part?

A template is the full layout for a type of page. A template part is a section, such as a header or footer, that can be reused inside several templates.

Is a synced pattern the same as a template part?

They behave similarly because both update everywhere when edited, but synced patterns are designed for content inside pages, while template parts are part of the site's layout structure.

Will editing a template change every page?

It changes every page that uses that template. Check which template a page uses before editing, and test larger changes on a staging site.

Can I undo changes to a template?

In most cases you can reset a customised template to the theme's original version, but this removes your edits. Keep a backup and a note of changes before making large adjustments.

Does my site use the site editor?

Only if it uses a block theme. Classic themes manage layout differently, usually through theme files, the customiser and widgets.
