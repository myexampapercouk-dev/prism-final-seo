Shopify URL Redirects: When to Use Them and How to Set Them Up

A practical guide to Shopify URL redirects: when you need them, how to add them one by one or in bulk, and how to avoid redirect chains and loops.

By the Prism Works Studio team · 1 November 2026 · 7 min read

Key takeaways

  • Add a redirect whenever a product, collection, page or blog post address changes or is removed, so visitors and search engines reach the right place.
  • Point each old address straight to its closest equivalent, not to the homepage, and avoid chains of redirects.
  • Shopify redirects only work for addresses that no longer exist, so a live page at the old address will block them.

A redirect sends anyone who visits an old web address on to a new one. On a Shopify store, addresses change more often than people expect: products get renamed, collections are merged, seasonal ranges end and whole stores move from another platform. Without redirects, those old addresses lead to an error page, which frustrates shoppers and wastes any search visibility the old page had.

This guide explains when Shopify redirects are needed, how to create them, how to handle larger moves and the mistakes to avoid. If you are relaunching a whole site, our guide to website redirects when relaunching covers the wider planning.

What a Shopify redirect does

Shopify redirects are permanent redirects. When someone requests the old address, the server tells their browser, and any search engine, that the page has moved for good and gives the new address. Browsers follow the instruction instantly, so most visitors never notice.

For search engines, a permanent redirect is a signal to update their index and, over time, to transfer the old page's standing to the new one. That transfer is not instant or guaranteed, but without a redirect the old page's value is simply lost.

When you need a redirect

Add a redirect whenever an address that people or search engines might know about stops working. Typical situations include:

  • Changing a product or collection handle. The handle is the last part of the address. Editing it changes the address.
  • Deleting a product that is permanently discontinued.
  • Merging or retiring collections. For example, combining two similar collections into one.
  • Restructuring pages or blog posts. Renaming, merging or removing content.
  • Moving to Shopify from another platform. Shopify's address format is fixed, so most old addresses will change.
  • Fixing old marketing links. Printed materials, emails or adverts that point to addresses which no longer exist.

Automatic redirects when you change a handle

When you edit the handle of a product, collection, page or blog post in the search engine listing section, Shopify shows a checkbox to create a redirect from the old address. It is usually ticked by default. Leave it ticked unless you have a specific reason not to.

Check that the redirect was created by visiting the old address afterwards. It is also worth recording handle changes somewhere, so you can trace any problems later.

Adding a redirect manually

In the Shopify admin, go to Content, then Menus, and look for URL redirects. In some admin layouts the option sits under Online Store, then Navigation. Choose to create a redirect and fill in two fields:

  • Redirect from. The old address, starting with a forward slash, for example /products/old-name.
  • Redirect to. The new address, either a path on your store or a full web address.

Save it, then test by visiting the old address in a private browser window.

Adding redirects in bulk

For larger changes, such as a platform migration or a big tidy-up, Shopify lets you import redirects from a spreadsheet saved as a CSV file. The file has two columns, one for the old path and one for the new destination. The redirects screen includes an import option and Shopify provides a template format.

Before importing:

  • Build a full list of old addresses. Use your old sitemap, analytics, search console data and any crawl of the old site.
  • Map each one to its closest match. A product to the same or nearest product, a category to the equivalent collection.
  • Check for duplicates and typos. One mistake can send a lot of visitors to the wrong place.
  • Import, then spot-check. Test a sample of addresses from each type of page.

Where to point a redirect

The destination matters as much as the redirect itself. The aim is to send people to the page that best meets what they were looking for.

  • Renamed product: redirect to the same product at its new address.
  • Discontinued product with a replacement: redirect to the replacement.
  • Discontinued product with no replacement: redirect to the most relevant collection.
  • Merged collection: redirect to the combined collection.
  • Removed blog post: redirect to the closest related post or the blog category.

Avoid sending everything to the homepage. It may look tidy, but visitors arrive somewhere that does not match what they wanted, and search engines may treat a homepage redirect for an unrelated page much like a missing page.

Sometimes there is no sensible destination. In that case, letting the address return a helpful 404 page is acceptable. Our 404 page design guide covers how to make that page useful.

Why a redirect might not work

A page still exists at the old address

Shopify only applies a redirect if nothing lives at the old address. If a product or page is still published there, even if hidden from menus, the redirect is ignored. Delete or change the handle of the old item first.

The address format is wrong

The "from" field should be a path starting with a forward slash, without your domain. Check for extra spaces, capital letters or trailing characters.

Query strings and special cases

Some addresses include tracking or filter parameters after a question mark. Redirect handling for these can be limited, so test the exact addresses that matter.

Caching

Your browser may remember an earlier response. Test in a private window or on a different device.

Avoiding chains and loops

A redirect chain happens when address A redirects to B, which redirects to C. Each step slows things down a little and makes it harder for search engines to follow. Chains often build up over years of renaming.

When you add a new redirect, check whether the old address already has redirects pointing to it, and update those to point straight to the final destination. Periodically export your redirects and look for chains.

A loop happens when A points to B and B points back to A. Browsers show an error and nobody can reach the page. Loops usually come from quick fixes made without checking the existing list.

Keeping your redirect list healthy

  • Review after big changes. After a range refresh or migration, check for new errors in your search console coverage reports.
  • Update internal links too. Redirects are a safety net, not a substitute for linking directly to the right page in your menus and content.
  • Keep a record. Note why major redirects were added, so future changes do not undo them by accident.
  • Do not delete old redirects casually. Old links on other sites and in customers' bookmarks can keep sending visits for a long time.

Planning changes so fewer redirects are needed

The simplest redirect is the one you never need. Choosing clear, lasting handles from the start reduces how often addresses change. Avoid putting years, seasons or temporary details in handles for products and collections that will stay on sale. A collection called summer-sale-and-new-in will feel out of date quickly, while a handle such as linen-dresses can stay put for years.

Before renaming anything, ask whether the change is worth it. Updating the visible title of a product does not require changing its handle. You can give a product a fresh name on the page while keeping the same address, which avoids a redirect altogether. Save handle changes for cases where the old address is genuinely misleading or confusing.

FAQs

Are Shopify redirects permanent?

Yes. Shopify URL redirects are permanent redirects, which tell browsers and search engines the page has moved for good.

Why is my Shopify redirect not working?

The most likely reason is that something still exists at the old address. Shopify only redirects addresses that would otherwise show an error. Also check the format of the path and test in a private window.

Should I redirect discontinued products?

If there is a replacement or a closely related collection, yes. If there is genuinely nothing relevant, a helpful 404 page can be the better option.

Can I import redirects in bulk?

Yes. Shopify lets you import a CSV file with the old paths and new destinations from the URL redirects screen.

Does Shopify create redirects automatically?

When you change a handle, Shopify offers to create a redirect from the old address, usually ticked by default. It does not create redirects when you delete items.

Do redirects hurt SEO?

Well-planned redirects protect search visibility when addresses change. Problems come from chains, loops and redirecting unrelated pages to the homepage.
