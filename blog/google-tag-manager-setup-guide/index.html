How to Set Up Google Tag Manager for a Small Business Website

How to set up Google Tag Manager step by step: create a container, install it, add GA4 and ad tags, respect cookie consent and test before you publish.

By the Prism Works Studio team · 8 November 2026 · 8 min read

Key takeaways

  • Google Tag Manager is a container that lets you add and manage tracking tags without editing website code every time.
  • Plan which tags, triggers and events you need before building anything, and keep names consistent so others can follow your set-up.
  • Always connect tags to your cookie consent tool and use Preview mode to test before you publish a new version.

To set up Google Tag Manager, create an account and a container for your website, add the two container snippets to every page, then build tags (what to send), triggers (when to send it) and variables (extra details) inside the Tag Manager interface. Test everything in Preview mode and only then publish a version.

This guide explains each step in plain English for UK small business owners. It covers what Tag Manager is for, how to plan a tidy set-up, how to add Google Analytics 4 and advertising tags, how cookie consent fits in, and the mistakes that cause broken tracking. Interfaces change often, so check Google's current Tag Manager help pages for the exact menus and wording before you start.

What Google Tag Manager does

Most marketing tools ask you to add a small piece of code, called a tag, to your website. Analytics, Google Ads conversion tracking, the Meta Pixel and the TikTok Pixel all work this way. Without a tag manager, each new tag means editing the site's code or theme, which usually needs a developer and can slow the site down if old tags are never removed.

Google Tag Manager, often shortened to GTM, puts one container on your site. Every other tag lives inside that container and is managed from a web interface. You decide when each tag fires, what data it sends, and you can pause or remove it without touching the site's files. It also keeps a version history, so a mistake can be rolled back.

It is not a reporting tool. Tag Manager sends data to tools such as GA4 or Google Ads, and you read the results there. If you have not yet set up analytics, start with our GA4 setup guide and come back to this once you know which events matter.

Plan before you build

The most common reason a Tag Manager container becomes a mess is that tags were added one at a time with no plan. Before you open the interface, write a short tracking plan in a spreadsheet. List the actions on your site that matter to the business, such as enquiry forms, phone number clicks, email link clicks, bookings or purchases. For each one, note which tools need to know about it and how you will recognise it, for example a thank-you page URL or a button click.

Keep the list short. Three to six meaningful actions are usually enough for a small business website. Tracking every scroll and every click creates noise that nobody reads. Our guide to website analytics for small business explains how to pick measures that lead to decisions.

Agree a naming convention at the same time. A simple pattern such as tool, type and detail works well, for example "GA4 - Event - Enquiry form" or "Google Ads - Conversion - Booking". Consistent names make the container easy to hand over to a colleague or a studio later.

How to set up Google Tag Manager step by step

  1. Create an account and container. Sign in with a Google account the business controls, not a personal one that might leave with an employee. Create an account named after the business and a container for your website, choosing the web option.
  2. Install the container code. Tag Manager gives you two snippets. One goes as high as possible in the head of every page and the other just after the opening body tag. On WordPress you can use a reputable plugin or your theme settings. On Shopify, check the current help pages, because the recommended method for tracking and checkout pages has changed over time and may involve customer events or an app.
  3. Confirm the container loads. Use Preview mode, which opens your site with a debugging panel. If the panel connects, the container is installed correctly.
  4. Add your Google tag. Create a Google tag using your GA4 measurement ID and set it to fire on all pages. This handles basic page views.
  5. Add event tags. For each action in your plan, create a tag and a matching trigger. A form submission might use a page view trigger on the thank-you page, while a phone click might use a click trigger on links that start with tel.
  6. Add advertising tags. Add Google Ads conversion tags, the Meta Pixel or other platform tags as needed. Our guides to Google Ads conversion tracking and setting up the Meta Pixel cover what to track for each.
  7. Test in Preview mode. Walk through each action on the site and check the right tags fire once, at the right moment, and not on pages where they should not.
  8. Publish a named version. Give the version a clear name and short description of what changed, then publish.

Cookie consent, UK GDPR and PECR

In the UK, PECR and UK GDPR mean most analytics and advertising cookies need the visitor's consent before they are set. Tag Manager does not handle consent on its own. You need a consent tool, often called a cookie banner or consent management platform, and your tags need to respect the choice the visitor makes.

Many consent tools integrate with Tag Manager and support Google's consent mode, which adjusts how Google tags behave depending on the visitor's choice. Non-Google tags usually need triggers that only fire once consent for the relevant category has been given. The details vary by tool, so follow your consent provider's documentation and Google's current consent mode guidance. Our article on cookie banner design in the UK covers the visitor-facing side. This is general information, not legal advice, and you should check the ICO's guidance for your own situation.

Using the data layer for ecommerce

For online shops, the most useful information, such as order value, currency and products bought, is not visible on the page in a reliable way. The answer is the data layer. Your shop platform or a developer pushes structured information into it when something happens, and Tag Manager reads it through variables.

Many ecommerce platforms and apps can push standard ecommerce events for you. Check what yours already provides before building anything custom, because duplicate purchase events are a common cause of inflated revenue figures in GA4 and ad platforms.

Testing and keeping the container healthy

Preview mode is your main testing tool. It shows which tags fired on each event, which did not, and why. Pair it with the real-time or debug views in GA4 and the testing tools in each ad platform. If your site has a staging copy, test there first. Our guide to website staging and testing explains how that works.

Once live, review the container every few months. Remove tags for tools you no longer use, pause anything that is not needed, and check that triggers still match your pages after any redesign. Every extra script adds weight, so a lean container also helps with website speed.

Common Google Tag Manager mistakes

  • Installing tags twice. If GA4 is added directly in the theme and again in Tag Manager, page views double. Pick one method.
  • Triggers that are too broad. A conversion tag firing on all pages instead of the thank-you page will make campaigns look far better than they are.
  • Ignoring consent. Tags that fire before a visitor accepts cookies create compliance risk.
  • Personal data in tags. Never send names, email addresses or phone numbers to analytics tools in page URLs or event details.
  • No access control. Give people the lowest permission level they need, and remove access when a supplier or staff member leaves.
  • Unnamed versions. Without notes, nobody knows what changed or which version to roll back to.

Tracking campaign sources alongside Tag Manager

Tag Manager tells tools what people did. Campaign tagging tells them where people came from. Use consistent UTM parameters on links in emails, social posts and offline QR codes so that your analytics can attribute visits properly. Our UTM tracking links guide shows a simple naming system.

FAQs

How do I set up Google Tag Manager?

Create an account and a web container, add the two container snippets to every page of your site, then create tags, triggers and variables for the tools and actions you want to track. Test in Preview mode and publish a named version once everything fires correctly.

Is Google Tag Manager free?

The standard version of Google Tag Manager is free to use. There is a paid enterprise version aimed at large organisations, but small businesses rarely need it. Check Google's current product pages for details.

Do I still need GA4 if I use Tag Manager?

Yes. Tag Manager only sends data. GA4 is where that data is stored, processed and reported. You use Tag Manager to install and control the GA4 tag and events.

Will Google Tag Manager slow down my website?

The container itself is light, but every tag inside it adds scripts. A container full of unused tags can slow pages down. Review it regularly and remove anything you no longer need.

Can I use Tag Manager on Shopify or WordPress?

Generally yes, though the method differs. WordPress sites often use a plugin or theme setting. Shopify has its own approach for tracking, particularly on checkout pages, so follow Shopify's current help pages before installing anything.

Who should own the Tag Manager account?

The business should own the account, using a company Google login. Agencies and freelancers should be added as users with appropriate permissions, so access can be removed without losing the container.
