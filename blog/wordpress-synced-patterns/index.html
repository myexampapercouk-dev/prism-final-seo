WordPress Synced Patterns: How to Reuse Content Without Copying It

What WordPress synced and unsynced patterns are, how they replaced reusable blocks, and how to use them for calls to action, contact details and page layouts.

By the Prism Works Studio team · 1 November 2026 · 7 min read

Key takeaways

  • Synced patterns let you edit content in one place and have the change appear everywhere that pattern is used.
  • Unsynced patterns act as starting templates, so each copy can be edited independently without affecting the others.
  • A small, well-named library of patterns keeps pages consistent and makes it easier for your team to build new content.

Most websites repeat certain pieces of content across many pages. A call to action at the end of every service page, a box with opening hours, a short disclaimer or a set of trust signals might appear in dozens of places. If each copy is created by hand, updating them means hunting through the site and editing each one, and it is easy to miss a few.

WordPress patterns solve this. Patterns let you save a group of blocks and reuse it, either as a linked copy that updates everywhere at once or as a starting template you adapt each time. This guide explains how patterns work in the block editor, the difference between synced and unsynced patterns, and how to use them sensibly on a business website.

What are WordPress patterns?

A pattern is a saved arrangement of blocks. It might be as small as a single button or as large as a full page section with headings, images, columns and text. Once saved, a pattern can be inserted into posts and pages from the block inserter, just like an individual block.

WordPress offers patterns from several sources: some are bundled with WordPress itself, some come with your theme, and you can create your own. This guide focuses mainly on patterns you create, as these are the ones tailored to your business.

Synced versus unsynced patterns

When you create a pattern, WordPress asks whether it should be synced. This is the most important choice.

Synced patterns

A synced pattern is linked everywhere it is used. Edit the pattern once and the change appears on every page that includes it. This is ideal for content that should always be identical, such as:

  • A standard call to action box.
  • Contact details or opening hours.
  • A legal or regulatory statement that must stay consistent.
  • A promotional banner that runs across several pages for a limited period.

Unsynced patterns

An unsynced pattern works like a template. When you insert it, WordPress places a copy of the blocks that you can then change freely, without affecting the original pattern or any other copies. This suits layouts you want to reuse with different content each time, such as:

  • A team member profile layout.
  • A case study section structure.
  • A service page hero with heading, text and button.
  • A frequently asked questions layout.

Where reusable blocks went

If you have used WordPress for a while, you may remember reusable blocks. These were renamed and folded into patterns, and what used to be a reusable block is now a synced pattern. Existing reusable blocks on older sites should appear in the patterns area.

Creating a pattern

The broad steps are straightforward, although the exact labels can vary slightly between WordPress versions:

  1. Build the content you want to reuse in the block editor, using whichever blocks you need.
  2. Select the blocks, often by wrapping them in a group first so they behave as a single unit.
  3. Open the block options menu and choose the option to create a pattern.
  4. Give the pattern a clear name and, if offered, assign it to a category.
  5. Choose whether it should be synced, then save.

Your pattern then appears in the block inserter under patterns, ready to be added to other pages. In block themes, patterns can also be managed through the Site Editor.

Editing and managing patterns

Synced patterns can be edited either from within a page, by choosing to edit the original, or from the patterns management screen. Remember that editing a synced pattern changes it everywhere, so it is worth checking where it is used before making significant changes.

If you need one page to differ from the rest, you can detach that instance of a synced pattern. Detaching converts it into regular blocks on that page only, so future updates to the pattern will no longer reach it. Use this deliberately, because detached copies can drift out of date.

Recent versions of WordPress have also introduced ways to allow certain parts of a synced pattern, such as specific text or images, to be overridden on individual pages while the structure stays linked. Availability and behaviour of this feature can depend on your WordPress version and theme, so check what your site supports before relying on it.

Good uses for patterns on a business website

Calls to action

A consistent call to action at the end of service pages or blog posts is a natural fit for a synced pattern. If your offer or contact method changes, one edit updates them all. Our guide to call-to-action buttons covers what makes them effective.

Contact and location details

Phone numbers, email addresses and opening hours often appear in several places. Keeping them in a synced pattern reduces the chance of an old number lingering on a forgotten page.

Standard page sections

Unsynced patterns for common layouts, such as a services overview grid or a page hero, help keep the design consistent while allowing different content. This is particularly helpful when several people create pages.

Seasonal or temporary messages

A banner announcing holiday closing times or a temporary offer can be added as a synced pattern, then edited or removed from one place when it is no longer needed.

Blog post elements

Elements like an author box, a newsletter prompt or a standard closing paragraph can be saved as patterns so that every post follows the same structure.

Organising a pattern library

Patterns are most useful when people can find the right one quickly. A few habits help:

  • Use descriptive names. "Service page CTA" is more helpful than "Box 2".
  • Use categories. Grouping patterns by purpose, such as calls to action, layouts or contact details, makes them easier to browse.
  • Remove patterns you no longer use. An overgrown library makes it harder to pick the right option. Check whether a synced pattern is in use before deleting it.
  • Keep the number manageable. A small set of well-designed patterns is generally more useful than many near-duplicates.

Patterns, roles and teams

If several people edit your site, patterns help everyone produce pages that look consistent. However, editing a synced pattern affects every page that uses it, so think about who should be allowed to make those changes. WordPress roles control what different users can edit, and our guide to WordPress user roles explains how to set sensible permissions.

It also helps to agree a simple rule within the team, such as checking with someone before editing a synced pattern used site-wide.

Patterns versus template parts

In block themes, template parts such as headers and footers also behave like shared content, because editing one updates every template that uses it. The distinction is that template parts form the structure of your theme, while patterns are pieces of content inserted into posts, pages or templates. Site-wide elements like the header and footer are usually best handled as template parts, while repeated content within pages suits patterns.

Things to watch out for

  • Editing a synced pattern by accident. Because changes apply everywhere, a quick edit intended for one page can alter many. Detach first if you only want to change one instance.
  • Theme-dependent styling. Patterns use your theme's styles, so they may look different after a theme change. Review key patterns after any redesign.
  • Plugin blocks inside patterns. If a pattern relies on blocks provided by a plugin, deactivating that plugin can break the pattern wherever it appears.
  • Revisions. Before making significant changes to an important synced pattern, consider making a backup or testing on a staging site. Our guide to website staging and testing explains how this works.

FAQs

What is the difference between a synced and an unsynced pattern?

A synced pattern stays linked everywhere it is used, so editing it updates every copy. An unsynced pattern inserts independent copies of its blocks, which can each be edited without affecting the original or other copies.

What happened to reusable blocks in WordPress?

Reusable blocks were renamed and became synced patterns. They work in a similar way, and existing reusable blocks on older sites should appear among your patterns.

Can I change a synced pattern on just one page?

You can detach the pattern on that page, which turns it into regular blocks you can edit freely. That copy will no longer receive future updates. Some recent WordPress versions also allow selected parts of a synced pattern to be overridden per page, depending on your setup.

Do patterns work with classic themes?

Patterns are a block editor feature, so they are available wherever you use the block editor for posts and pages, including on sites with classic themes. Managing patterns through the Site Editor applies to block themes.

Will deleting a synced pattern remove it from my pages?

Deleting a synced pattern that is still in use can leave affected pages with missing content or an error message in its place. Check where a pattern is used, and replace or detach those instances, before deleting it.
