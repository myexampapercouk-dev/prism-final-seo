WooCommerce Product CSV Import and Export: A Practical Guide

How to use WooCommerce product CSV import and export: preparing the file, mapping columns, variations, images, updating prices and stock, and avoiding errors.

By the Prism Works Studio team · 8 November 2026 · 7 min read

Key takeaways

  • Export a few existing products first and use that file as your template, so your columns match what WooCommerce expects.
  • Use SKUs or IDs consistently, because they are how an import knows whether to update an existing product or create a new one.
  • Back up the site, test a small batch on staging and check variations, images and prices before importing the full catalogue.

WooCommerce product CSV import lets you add or update many products at once from a spreadsheet, and the matching export gives you a spreadsheet of products you already have. Both tools sit on the Products screen in your WordPress admin, behind the Import and Export buttons. Used carefully, they save hours on new ranges, price changes and stock updates. Used carelessly, they can overwrite a catalogue in seconds.

This guide is for UK shop owners and teams who want to use the built-in WooCommerce importer and exporter with confidence. It covers preparing the file, mapping columns, variable products, images, bulk updates and the mistakes that cause the most trouble. Extensions can add more advanced import options, but the core tools are enough for most shops.

Before you import anything

  1. Back up the site. A full backup, including the database, means a bad import can be undone. Our website backup and recovery plan guide explains what to keep.
  2. Use a staging copy for big jobs. Test large or unfamiliar imports away from the live shop first, as set out in our guide to staging and testing.
  3. Export a sample. Export a handful of existing products of each type to see exactly how columns are named and filled.
  4. Agree your SKUs. Every product and variation should have a unique SKU before you start.

How to do a WooCommerce product CSV import

  1. Prepare your file using your exported sample as the template, saved as a UTF-8 CSV.
  2. In WordPress, go to Products and choose Import.
  3. Upload the file. If you are updating existing products, tick the option to update products that already exist.
  4. Check the column mapping screen. WooCommerce tries to match your headings to its fields; correct any it misses and set unneeded columns to be ignored.
  5. Run the import and wait for it to finish without closing the window.
  6. Read the summary. It shows how many products were created, updated, skipped or failed.
  7. Spot-check products in the admin and on the front end.

Preparing the CSV file

Most import problems start in the spreadsheet. A few rules help:

  • Save as UTF-8. Otherwise symbols such as £ and accented characters can turn into strange characters.
  • Keep headings unchanged. If you use WooCommerce's own exported headings, mapping is almost automatic.
  • Watch number formats. Prices should be plain numbers without the £ sign, using a full stop for decimals.
  • Protect SKUs and barcodes. Spreadsheet software can strip leading zeros or turn long numbers into scientific notation. Format those columns as text.
  • Separate multiple values carefully. Categories, tags and images that hold several values use specific separators; follow the format shown in your export.
  • Use category paths for subcategories. Exports show how parent and child categories are written, so copy that pattern.

Descriptions can include basic HTML. If you are writing new product copy at the same time, our guide to ecommerce product descriptions covers what makes them work for shoppers and search.

Importing variable products

Variable products, such as a jumper in several sizes and colours, are the trickiest part of any import. Each needs one row for the parent product and one row for each variation.

  • The parent row has the type set to variable, the product name, description, categories and the full list of attribute values.
  • Each variation row has the type set to variation, a parent reference pointing to the parent's SKU or ID, its own SKU, price and stock, and the specific attribute values for that variation.
  • Attribute names must match exactly across the parent and its variations, including capital letters and spaces.

The easiest way to get this right is to create one variable product by hand, export it and copy its structure. Our guide to product variants and bundles explains how to plan variations before you build them.

Importing product images

The importer can fetch images from URLs listed in the images column. The first image becomes the main product image and the rest go into the gallery. The images must be publicly reachable when the import runs.

Compress and resize images before you upload them anywhere. Large originals slow down both the import and the shop. Our guide to website image optimisation covers sizes and formats. For big catalogues, consider importing product data first and images in a second pass, so a slow image server does not cause the whole job to time out.

Bulk updates with a CSV

CSV imports are excellent for changing many products at once, for example a seasonal price change or a stock count. The safe pattern is:

  1. Export only the products and columns you need, plus the ID or SKU.
  2. Edit only the values that should change.
  3. Delete any columns you are not changing, so you cannot overwrite them by accident.
  4. Import with the update existing products option ticked.
  5. Check a sample of products afterwards.

Be careful with empty cells. Depending on the column, a blank value may be ignored or may clear existing data. Removing unneeded columns is the simplest protection.

Exporting products

The exporter lets you choose which columns, product types and categories to include, and whether to add custom meta from extensions. Exports are useful for:

  • Creating templates for new products.
  • Reviewing the catalogue for missing descriptions, prices or SKUs.
  • Sharing product data with suppliers or marketplaces.
  • Keeping a snapshot before a big change.
  • Moving to another platform. Our WooCommerce to Shopify migration guide explains how product exports fit into a wider move, and our Shopify product CSV import guide covers the format on the other side.

FAQs

How do I do a WooCommerce product CSV import?

Go to Products in your WordPress admin and choose Import. Upload a UTF-8 CSV, tick the update option if you are changing existing products, check the column mapping and run the import. Then review the summary and spot-check products.

How do I export products from WooCommerce?

Go to Products and choose Export. Select the columns, product types and categories you want, decide whether to include custom meta, then generate the CSV. Exporting a small sample first is a good way to get a template.

Can I update prices in WooCommerce with a CSV?

Yes. Export the products with their ID or SKU and price columns, change the prices, remove other columns and import with the option to update existing products ticked. Check a few products afterwards.

Why does my WooCommerce import create duplicate products?

Usually because the update existing products option was not ticked, or the SKU or ID in the file does not match the existing product. The importer then treats each row as a new product.

How do I import variable products into WooCommerce?

Include one row for the parent product and one row per variation. Each variation row needs a parent reference and the exact attribute values. Building one variable product by hand and exporting it gives you a reliable template.

Can WooCommerce import product images from a CSV?

Yes, if the images column lists publicly reachable image URLs. The first becomes the main image and the rest the gallery. Optimise images first and split large imports into batches.
