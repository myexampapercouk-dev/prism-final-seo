Canonical Tags Explained: How to Handle Duplicate Pages on Your Website

Canonical tags explained in plain English: what they do, when to use them, how Shopify and WordPress handle them, and how to check yours are correct.

By the Prism Works Studio team · 8 November 2026 · 7 min read

Key takeaways

  • A canonical tag tells search engines which version of similar or duplicate pages is the main one to show in results.
  • It is a strong hint rather than an order, so internal links, sitemaps and redirects should all point to the same preferred URL.
  • Most platforms add canonical tags automatically, but filters, parameters, copied content and redesigns often cause problems worth checking.

A canonical tag is a line of code in a page's head that tells search engines which URL is the preferred version when several pages show the same or very similar content. It helps Google consolidate signals onto one page and choose the right address to show in search results. Most small business websites need it working quietly in the background, not tweaked by hand on every page.

This guide explains canonical tags in plain English for UK small business owners. It covers why duplicates happen, when to use a canonical tag instead of a redirect or noindex, how Shopify and WordPress handle them, and how to check yours. Platforms and Google's guidance change, so check Google Search Central and your platform's current help pages for the exact details.

Why duplicate pages happen

Most duplicate content is accidental and harmless in intent. Common causes include:

  • URL variations, such as http and https, www and non-www, or with and without a trailing slash.
  • Tracking parameters added to links in emails and ads, which create new addresses for the same page.
  • Filters and sorting on ecommerce category pages, where each combination makes a different URL.
  • Products in several collections, which some platforms can show at more than one address.
  • Print versions, tag archives and pagination that repeat content from other pages.
  • Copied content, such as manufacturer product descriptions or articles republished on another site.

When search engines find several versions, they have to choose one to show. If your signals are mixed, they may pick a version you would not choose, or split links and attention between them. Canonical tags are one of the main ways to state your preference.

Canonical tags explained: how they work

A canonical tag is a link element in the head of the page with the attribute rel set to canonical and the href set to the preferred URL. A page can point to itself, which is called a self-referencing canonical, or to another page that it duplicates.

Google treats the canonical tag as a strong hint rather than a strict instruction. It also looks at redirects, internal links, sitemaps, https and other signals. If those disagree with your tag, Google may choose a different canonical. You can see Google's choice using the URL Inspection tool in Search Console. Our Google Search Console setup guide explains how to get access.

Canonical, redirect or noindex?

Canonical tags are not the only way to deal with duplicates. Choosing the right tool depends on whether visitors still need the duplicate page.

Old page replaced by a new one301 redirectVisitors and search engines both move to the new page

How Shopify and WordPress handle canonical tags

Most modern platforms add self-referencing canonical tags automatically, which covers the basics for many small sites.

Shopify

Shopify themes generally output a canonical tag on each page. Products can appear inside collection URLs, and the canonical usually points to the main product URL. Filtered and sorted collection views are a common source of extra URLs. Our guides to Shopify product filters and structuring Shopify collections help keep this tidy, and our wider Shopify SEO guide covers the rest. Customised themes and apps can sometimes alter or duplicate canonical tags, so check after big theme changes.

WordPress and WooCommerce

WordPress adds canonical tags to single posts and pages, and SEO plugins typically extend this to archives and let you set a custom canonical on individual pages. WooCommerce stores need the same care with filtered shop pages and product variations. Our WooCommerce SEO guide covers the ecommerce side. Avoid running two SEO plugins at once, as both may output canonical tags.

How to check your canonical tags

  1. View the page source. Search for the word canonical. There should be one tag, in the head, pointing to a full, working URL.
  2. Use URL Inspection. Compare the user-declared canonical with the Google-selected canonical for key pages.
  3. Review the page indexing report. Look at reasons relating to duplicates and alternate pages to spot patterns.
  4. Crawl the site. An SEO crawler can list every canonical tag and flag missing, multiple or broken ones.
  5. Check your sitemap. It should list canonical URLs only. Our XML sitemap guide explains why.

Common canonical tag mistakes

  • Every page pointing to the home page. Usually a theme or plugin error, and it can stop inner pages appearing in search.
  • Canonicals pointing to redirected or missing pages. Always point to a live page that returns a normal response.
  • Leftover staging addresses. After a launch, canonicals sometimes still point to the development domain.
  • Multiple tags on one page. Conflicting tags may be ignored altogether.
  • Canonical plus noindex on the same page. These send mixed messages. Pick the one that matches your intent.
  • Canonicalising different content. Pages that are genuinely different, such as separate services or locations, should usually have their own self-referencing canonicals.
  • Internal links to non-canonical URLs. Link to the preferred version in menus and content so your signals agree.

Canonical tags and tracking parameters

Links in emails, social posts and ads often carry tracking parameters after a question mark in the URL. Each variation is technically a different address, even though the page is identical. A self-referencing canonical on the clean URL tells search engines to ignore the extra versions, so your reports stay accurate and search results show the tidy address.

The same applies to session IDs, sort orders and search parameters added by some booking systems or shop apps. If you see many parameter URLs in Search Console, check that the canonical on those pages points to the clean version, and avoid linking internally to parameter URLs where you can.

Canonicals when moving or merging content

If you merge two similar blog posts into one stronger article, redirect the weaker URL to the new one rather than relying on a canonical tag. If you run the same product range on two of your own websites, for example a trade site and a retail site, decide which should rank for each page and point the other version's canonical to it. Write this decision down so future content and redesigns keep it consistent, because canonical rules are easy to lose when a theme is replaced.

Do canonical tags matter for a small site?

For a small brochure site with a handful of pages, the platform defaults are often enough, and you rarely need to set a canonical by hand. They matter more for online shops with filters and many product URLs, sites with content syndicated elsewhere, and any site after a redesign or platform move. If you are seeing duplicate warnings in Search Console or key pages are being replaced in results by odd URLs, canonicals are one of the first things to check. FAQs

What are canonical tags explained simply?

A canonical tag is a short line of code that tells search engines which URL is the main version of a page when similar or identical content exists at more than one address.

Does every page need a canonical tag?

It is good practice for indexable pages to have a self-referencing canonical tag. Most modern platforms add these automatically, so check they are present rather than adding them by hand.

Will Google always follow my canonical tag?

No. Google treats it as a strong hint and may choose a different URL if other signals, such as internal links, sitemaps or redirects, point elsewhere. Make all your signals consistent.

Is duplicate content a penalty?

Generally, ordinary duplication within your own site is not treated as a penalty. It can, however, split signals and lead Google to show a version you did not intend, which canonical tags help prevent.

Should I use a canonical tag or a redirect?

Use a redirect when the old page should no longer be visited. Use a canonical tag when several versions need to stay available to visitors but you want one shown in search.

How do I see which canonical Google has chosen?

Use the URL Inspection tool in Google Search Console. It shows the canonical you declared and the one Google selected, so you can spot mismatches.
